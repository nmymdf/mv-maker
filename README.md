# MV 製作工具

選歌、匯入歌詞、選照片和影片，自動做出 MV（MP4，橫式或直式）。

*作者：ArchieKUO*

## 使用方法
1. 下載 `MVMaker_v版本.zip`，解壓縮，打開資料夾裡的 `MVMaker.exe`。
2. 按「選歌曲」。歌曲旁邊如果有同名的 `.lrc` 歌詞檔，會自動讀進來；沒有就按「匯入歌詞」。
3. 按「選素材資料夾」或「加入檔案」。有長影片的話，按「自動挑片段」。
4. 右邊「風格」分頁選字體、顏色、照片動態等。
5. 按「播放」預覽，滿意了按「輸出 MP4」。

專案會自動存在歌曲旁邊（`歌名.MV專案.json`），下次選同一首歌就會接著做。
